# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work and not the person, and
do not harass anyone. Behaviour that makes others unwelcome is not acceptable in the issue tracker,
in pull requests or in any other project space.

Report problems to the maintainer at enino@uninorte.edu.co. Reports are handled confidentially.
